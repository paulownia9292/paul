# Anima用 女性制服 資料プロンプト 50種

漫画の作画資料向け。全身・白背景・正面立ちで、服の構造が見やすい設定にしています。

## 共通プロンプト(各プロンプトの先頭に付ける)

```
masterpiece, best quality, score_7, safe, newest, 1girl, solo, full body, standing, looking at viewer, arms at sides, simple background, white background,
```

## ネガティブプロンプト

```
worst quality, low quality, score_1, score_2, score_3, blurry, jpeg artifacts, sepia, bad hands, extra fingers, cropped, multiple views, text, watermark
```

## 使い方のコツ

- 後ろ姿が欲しいときは `from behind`、横は `from side` を追加
- 構造を見たいときは `arms at sides` を外して `hand on hip` などを入れるとシワの出方が変わる
- 色違いは色タグ(`navy blue` → `green` など)を差し替えるだけでOK
- 三面図風にしたいときは `multiple views, reference sheet` を追加し、ネガから `multiple views` を外す
